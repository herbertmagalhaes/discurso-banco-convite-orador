Discursos Públicos — cadastro de oradores

1. Publique a pasta/ZIP no Vercel.
2. O sistema usa o Supabase já configurado no index.html.
3. No Supabase, abra SQL Editor e execute o arquivo `supabase.sql` uma vez.
4. Entre com a mesma conta em outro dispositivo para ver os oradores salvos.
5. Em Oradores, cadastre Nome, Tema, Congregação do orador, Data, Horário e Período.
6. O botão “Gerar convite” abre uma versão pronta para impressão; no navegador escolha “Salvar como PDF”.

Importante:
- A chave usada no navegador é a chave pública (publishable/anon). Nunca coloque uma service_role no HTML.
- O convite foi adaptado ao PDF de referência enviado, com foto do Salão do Reino, tema, data, horário, orador e contatos da congregação Presidente Kennedy.
